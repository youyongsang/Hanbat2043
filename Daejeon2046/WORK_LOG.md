## 2026-09-23 (3차 — 엔진을 Kivy에서 Ren'Py로 전환 결정, Stage 1 변환)

**결정: Kivy 파서 대신 Ren'Py로 새로 짜기로 함**
- 계기: 박순임 4지선다 반복 메뉴를 만들다가, 옛 파서는 리액션 파일이 끝나고 돌아가는 위치가 선택지 4개 전부 동일해서 "메뉴로 루프백"이 안 됨 → `pass N`(하드코딩 줄 번호로 점프)이라는 땜빵을 엔진에 직접 추가해서 해결
- 렌파이는 `label`/`jump`/`menu`/`if` 조건부 캡션이 네이티브라 이런 문제 자체가 없다는 걸 알게 됨 → 취미 프로젝트라 수업 제약 없음 확인 후 엔진 교체 결정
- Kivy판(`Daejeon2046/screens/`, `main.py` 등, 지난 세션에 Hanbat2043에서 이식해둔 것)은 그대로 보존 — 렌파이판은 별도 폴더 `Daejeon2046_renpy/`에 신규 작성

**Ren'Py 변환 설계 확정**
- 화면전환(빈 줄) → NVL 모드, 블록 하나를 `\n` 묶어서 `say` 한 번 + 블록 끝마다 `nvl clear`
- `#태그` 리액션 파일 + `pass`/`pass N` 전부 폐기 → 그냥 `label`+`jump`. 리액션 파일 a~h로 쪼개던 것도 폐기, 각 메뉴 결과 라벨을 메뉴 바로 아래 인라인
- `statA~D`(반복 질문 추적) → 이름 붙은 변수 대신 범용 `flags` 딕셔너리 + `flag_set`/`flag_is` — 재사용 패턴 의도에 더 맞음
- `#이동:동이름` → `call call_travel_event(dong)` (여기만 `call` — 복귀해야 하므로)
- 기존 리액션 파일 서술 줄에 죽어있던 `%`/`&` 마크업(선택지 아닌 지문에 붙어서 이전 엔진에선 적용 안 되던 것) → 렌파이에서 `$ adjust_stat(...)` 실제 효과로 살림
- 스탯 아이콘 HUD는 1차 범위 밖, 텍스트 스탯 표시만 포함

**Stage 1 변환 완료 (`Daejeon2046_renpy/game/`)**
- `variables.rpy`, `start_story.rpy`, `main_story.rpy`, `travel_events.rpy`, `script.rpy`
- 범위: 오프닝 → 장씨 아저씨(배급소) → 박순임 4지선다 루프 메뉴(완충지대/오염구역/진앙지, 재질문 시 "이미 말했잖아" 분기) → 덕암동/목상동 → 완충지대 진입 → 오정동 이동 이벤트(`travel_ojeong_a`) 연결까지
- `label`/`jump`/`call` 대상 전부 교차 검증 완료 (오타 없음)
- **나는 렌파이 SDK가 없어서 실제 실행은 못 해봄** — pip 설치 불가, renpy.org에서 사용자가 직접 SDK 받아야 함. `renpy.exe Daejeon2046_renpy lint` 한 번 돌려보길 권장
